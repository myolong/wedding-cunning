청첩장 전달 멘트·문자 - 직접 줄 때, 모바일로 보낼 때, 청첩장 모임

작성 2026-11-12

청첩장은 결혼식 6~4주 전에 많이 돌립니다. 가까운 사람은 직접 만나서, 나머지는 모바일 청첩장으로 보내는 경우가 많습니다. 모바일로 보낼 때는 단체방보다 한 사람씩, 링크만 보내지 말고 인사를 한두 줄 덧붙이세요.

직접 건넬 때

친구에게

"나 드디어 결혼해! 5월 16일 토요일 12시야. 와 주면 진짜 기쁠 것 같아."

어른께

"제가 5월 16일에 결혼하게 되었습니다. 바쁘시겠지만 와 주시면 큰 힘이 될 것 같습니다."

모바일 청첩장 보낼 때

부드럽게

"○○아, 잘 지내지? 나 5월 16일에 결혼하게 됐어! 직접 만나서 주고 싶었는데 일정이 안 맞아서 모바일로 먼저 보내. 시간 되면 꼭 와 줘 :)"

정중하게

"안녕하세요, ○○님. 제가 5월 16일(토) 낮 12시에 결혼하게 되어 소식 전합니다. 직접 찾아뵙고 드려야 하는데 문자로 전하게 되어 죄송합니다. 시간 괜찮으시면 와 주시면 감사하겠습니다."

짧게

"저 5/16(토) 12시에 결혼합니다! 청첩장 보내 드려요. 시간 되시면 와 주세요 :)"

오랜만에 연락하는 사람에게

조심스럽게

"○○아, 정말 오랜만이다. 갑자기 연락해서 놀랐지? 나 결혼하게 돼서 소식 전하고 싶었어. 부담 갖지 말고, 시간 되면 얼굴 보면 좋겠다!"

오래 연락하지 않은 사이라면 청첩장만 보내기보다 안부를 먼저 묻고, 부담 갖지 말라는 말을 덧붙이는 게 좋습니다.

회사 동료에게

팀에 돌릴 때

"팀장님, 저 5월 16일에 결혼하게 되어 청첩장 드립니다. 주말이라 부담 갖지 마시고, 시간 되시면 와 주세요. 감사합니다."

청첩장 모임에서

시작할 때

"다들 바쁜데 와 줘서 고마워! 오늘은 내가 살게. 맛있게 먹어."

마칠 때

"오늘 시간 내 줘서 진짜 고마워. 결혼식 날 보자!"

자주 묻는 질문

청첩장은 언제 돌리나요?

결혼식 6~4주 전에 많이 돌립니다. 너무 늦으면 일정 잡기가 어렵고, 너무 이르면 잊어버리기 쉽습니다.

모바일 청첩장만 보내도 괜찮나요?

요즘은 모바일 청첩장도 많이 보냅니다. 다만 링크만 보내기보다 직접 못 드려 아쉽다는 인사를 한두 줄 덧붙이면 훨씬 정중하게 느껴집니다.

대본은 많이 쓰는 표현을 예시로 정리한 것이며, 상황과 관계에 맞게 고쳐 쓰세요.

함께 보면 좋은 가이드

  • 결혼식 감사 문자 - 하객·축의금·축가 해 준 사람별 대본결혼식 후 와 준 하객, 축의금만 보낸 분, 축가·사회를 해 준 사람, 어른께 보내는 감사 문자를 대본으로 정리했습니다. 보내는 시기와 주의할 점도 함께 확인하세요.
  • 부모님께 예단 생략 말하는 법 - 상황별 대본 6가지예단·함·이바지를 생략하거나 간소하게 하고 싶을 때 부모님께 말을 꺼내는 순서와 대본을 정리했습니다. 내 부모님께, 상대 부모님께 전할 때, 반대하실 때 쓰는 말을 부드럽게·정중하게·짧게 골라 쓰세요.
  • 결혼 비용 이야기 꺼내는 법 - 분담·신혼집·축의금 대본결혼 비용 분담, 신혼집 지원, 축의금 관리처럼 꺼내기 어려운 돈 이야기를 예비 배우자와 부모님께 말하는 순서와 대본을 정리했습니다.
