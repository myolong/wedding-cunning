말 컨닝 가이드

  • 부모님께 예단 생략 말하는 법 - 상황별 대본 6가지예단·함·이바지를 생략하거나 간소하게 하고 싶을 때 부모님께 말을 꺼내는 순서와 대본을 정리했습니다. 내 부모님께, 상대 부모님께 전할 때, 반대하실 때 쓰는 말을 부드럽게·정중하게·짧게 골라 쓰세요.
  • 결혼 비용 이야기 꺼내는 법 - 분담·신혼집·축의금 대본결혼 비용 분담, 신혼집 지원, 축의금 관리처럼 꺼내기 어려운 돈 이야기를 예비 배우자와 부모님께 말하는 순서와 대본을 정리했습니다.
  • 상견례 인사 멘트 - 소개·건배·마무리 대본상견례에서 두 사람이 자기 부모님을 소개하는 말, 첫인사, 건배 멘트, 식사 중 대화를 이어 주는 말, 마무리·배웅 인사를 대본으로 정리했습니다.
  • 축가·사회·축사 부탁 문자 - 거절해도 괜찮은 부탁 대본결혼식 축가, 사회, 축사, 덕담을 부탁할 때 보내는 문자와 만나서 하는 말, 수락 후 보낼 진행 정보와 사례 인사까지 대본으로 정리했습니다.
  • 청첩장 전달 멘트·문자 - 직접 줄 때, 모바일로 보낼 때, 청첩장 모임청첩장을 직접 건넬 때 하는 말, 모바일 청첩장을 보낼 때 문자, 오랜만에 연락하는 사람에게 보내는 문자, 회사 동료에게 돌릴 때, 청첩장 모임 인사까지 대본으로 정리했습니다.
  • 결혼식 감사 문자 - 하객·축의금·축가 해 준 사람별 대본결혼식 후 와 준 하객, 축의금만 보낸 분, 축가·사회를 해 준 사람, 어른께 보내는 감사 문자를 대본으로 정리했습니다. 보내는 시기와 주의할 점도 함께 확인하세요.
